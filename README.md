# おみくじ — digital omikuji

A single-page website featuring Japanese omikuji (おみくじ) — a paper fortune-telling device that is drawn in Japanese temples. An amateur project by a fan of Japanese culture: a single HTML file, no build or dependencies.

## What’s included?

- **“Home”** — a short story: What is omikuji, where did the custom come from (from the “water lot” 水くじ to the Edo period), how is it drawn at the temple, and what are the different levels of luck. With hand‑drawn SVG illustrations.
- **“Omikuji”** — the game itself: a six‑sided box; on a click, it shakes and produces a prediction sheet — the number 第 N 番, the level of luck (大吉, 吉, 中吉, 小吉, 末吉, 凶 — with realistic odds), a poem, advice in six categories (love, work, study, health, finance, desires), and a tip for the day.
- **“About the project”** — a small window with a few words about the project.

## Color schemes and themes

The header features four color schemes, each with its own dark version (8 combinations), and the choice is memorable:

- 🌸 **pink** — cherry blossoms, branches in the corners;
- 🌿 **green** — a bonsai park at the bottom of the page;
- 💧 **blue** — blue cherry blossoms;
- 🍁 **momiji** — an autumn red scheme, maple branches and falling maple leaves.

In any color scheme, petals or leaves slowly fall on the background. Animation is disabled when the system setting is "reduce motion".

## Technology

Vanilla HTML + CSS + JavaScript, all graphics are embedded SVG, icons are small inline SVG. No libraries or external scripts.
